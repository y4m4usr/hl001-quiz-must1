# HL002_PreQuiz — 名前当てクイズ最小構成

このフォルダはカラコンの名前当てクイズ（簡易版）のソース一式を格納します。今後の作業は以下の構成に沿って進めてください。

```
src/                … フロントエンド (index.html, CSS, JS)
assets/             … ロゴ・ボタンなどの静的素材
gas/                … Apps Script ファイル
questions/          … クイズ問題データ (JSON 想定)
docs/               … 手順書・テストログ
```

詳細な運用手順は `.sdd/HL001_quiz_only_operation.md` を参照してください。
