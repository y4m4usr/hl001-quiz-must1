# TEST_CHECKLIST（HL002 クイズ）

## 事前準備
- PC: Chrome 最新版
- モバイル: iOS Safari または Android Chrome のいずれか
- ローカルサーバー起動コマンド：`python -m http.server 4173 --directory src`

## 手順
1. トップ画面で「クイズをはじめる」ボタンが表示されることを確認
2. クイズ開始後、10 問目まで連続で出題されること
3. 正解・不正解でボタンの色と通知メッセージが切り替わること
4. 画像が読み込めない場合でもフォールバック文言が表示されること
5. 結果画面で正答率が表示され、「トップに戻る」でホームへ戻れること

## 検証ポイント
- PC / モバイル双方でレイアウト崩れがない
- 選択肢ボタンが連打できず、次問へ自然に遷移する
- JSON の更新内容が反映されている

## ログ（任意）
- 実施した端末・ブラウザ
- 気づいた改善点や既知の制約
