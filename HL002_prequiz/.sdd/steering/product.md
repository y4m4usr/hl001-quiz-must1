# Product Overview

## プロダクト概要
HL002 事前クイズは、JOYSOUND ブランド要素の理解度チェックを目的とした 10 問形式のブラウザクイズです。静的な HTML/CSS/JavaScript で構成され、質問データを差し替えるだけで内容を更新できます。

## 主要機能
- ホーム画面からクイズ開始・終了へ遷移する単一ページ UI
- `questions.json` からの問題読み込みとシャッフル出題（最大 10 問）
- 選択肢タップ時の正誤判定と即時フィードバック表示
- クイズ終了後の正答率計算と結果画面表示

## 対象ユースケース
新任スタッフ向け研修やキャンペーン準備時に、JOYSOUND のロゴやサービス名称を短時間で復習する場面で利用します。PC とモバイル両方のブラウザで動作し、研修担当者が JSON を更新して問題入れ替えが可能です。

## 価値提案
GitHub Pages などの静的ホスティングにそのまま配置でき、ビルド工程を持たないため運用コストが低い点が強みです。クライアントサイドのみで完結し、既存の HL001 クイズ構成から不要要素を削減した軽量版として迅速に展開できます。
