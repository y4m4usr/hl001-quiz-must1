了解です。HL002の最小構成に合わせて **(1) `questions.json` テンプレート** と **(2) React 雛形（Vite）** を、そのままコピペで動かせる形でお渡しします。

設計方針は **HL001 のクイズ仕様を崩さない**こと（4択 / 20秒タイマー / ヒント2種 / スコアは「正答率 + ヒント + タイム」の合計）で統一しています。ペイロード形（`questionId, imageUrls[左右], options[4], hints[2], answerKey`）とフローは既存の「phase1-core-quiz」に合わせ、スコア仕様は 200 点方式にしています。

UIフローは **ログイン無し → ホーム（開始ボタン）→ クイズ → リザルト → ホーム** の最小構成で、画像は GitHub Raw/（将来）jsDelivr を想定したURLを扱えるようにしています。

## 2) React 雛形（Vite / React 18, スマホファースト）

> ログイン無し。ホーム（開始ボタン）→ クイズ（10問／20秒／ヒント2種）→ リザルト（合計点/内訳）→ ホーム。
> 
> 
> スコアは「正答率（10点×正解数）+ ヒント（正解時のみ：未使用+5 / ヒント1+2 / ヒント2+0）+ タイム（正解時のみ：全問の余り秒合計÷4, 上限50）」で **最大200点**。

### `src/App.jsx`

```jsx
import React, { useEffect, useMemo, useState } from 'react';

const TIME_LIMIT_SEC = 20;         // 1問20秒（現行仕様）
// 自動でホームへ戻す場合は 0 以外に（例：5000=5秒後）。基本は手動にしています。
const AUTO_RETURN_MS = 0;

function computeScore(answers) {
  const correct = answers.filter(a => a.isCorrect);
  const accuracy = (correct.length * 10); // 最大100
  const hintBonus = Math.min(50, correct.reduce((sum, a) => {
    if (a.hint2Used) return sum + 0;
    if (a.hint1Used) return sum + 2;
    return sum + 5;
  }, 0));
  const totalLeft = correct.reduce((s, a) => s + (a.timeLeft ?? 0), 0);
  const timeBonus = Math.min(50, Math.floor(totalLeft / 4));
  const total = accuracy + hintBonus + timeBonus;
  return { accuracy, hintBonus, timeBonus, total };
}

export default function App() {
  const [stage, setStage] = useState('home'); // home | quiz | result
  const [questions, setQuestions] = useState([]);
  const [idx, setIdx] = useState(0);
  const [remaining, setRemaining] = useState(TIME_LIMIT_SEC);
  const [answers, setAnswers] = useState([]);
  const [hint1Used, setHint1Used] = useState(false);
  const [hint2Used, setHint2Used] = useState(false);

  const total = questions.length || 10;
  const current = questions[idx] || null;

  useEffect(() => {
    if (stage !== 'quiz') return;
    setRemaining(TIME_LIMIT_SEC);
    let cancelled = false;
    const interval = setInterval(() => {
      setRemaining(prev => {
        if (prev <= 1) {
          clearInterval(interval);
          if (!cancelled) handleAnswer(-1, true); // タイムアウト
          return 0;
        }
        return prev - 1;
      });
    }, 1000);
    return () => { cancelled = true; clearInterval(interval); };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [stage, idx]);

  const result = useMemo(() => computeScore(answers), [answers]);

  function resetAll() {
    setStage('home');
    setIdx(0);
    setRemaining(TIME_LIMIT_SEC);
    setAnswers([]);
    setHint1Used(false);
    setHint2Used(false);
  }

  async function startGame() {
    // public/questions.json を取得
    const res = await fetch('/questions.json', { cache: 'no-store' });
    const data = await res.json();
    const qs = data.questions || [];
    // 10問に満たない場合も動作するように切り上げ／安全化
    setQuestions(qs.slice(0, 10));
    setIdx(0);
    setAnswers([]);
    setHint1Used(false);
    setHint2Used(false);
    setStage('quiz');
  }

  function handleAnswer(pickedIndex, dueToTimeout = false) {
    if (!current) return;
    const correctIndex = typeof current.answerIndex === 'number'
      ? current.answerIndex
      : current.options?.indexOf?.(current.answerKey ?? '') ?? -1;

    const isCorrect = pickedIndex === correctIndex;
    const timeLeft = dueToTimeout ? 0 : remaining;
    const timeSpent = TIME_LIMIT_SEC - timeLeft;

    setAnswers(prev => ([
      ...prev,
      {
        qid: current.questionId,
        pickedIndex,
        isCorrect,
        timeLeft,
        timeSpent,
        hint1Used,
        hint2Used
      }
    ]));

    // 次へ or リザルト
    if (idx + 1 < questions.length) {
      setIdx(idx + 1);
      setHint1Used(false);
      setHint2Used(false);
    } else {
      setStage('result');
    }
  }

  useEffect(() => {
    if (stage !== 'result' || AUTO_RETURN_MS <= 0) return;
    const t = setTimeout(() => resetAll(), AUTO_RETURN_MS);
    return () => clearTimeout(t);
  }, [stage]);

  return (
    <div className="app">
      {stage === 'home' && (
        <section className="page home">
          <div className="card">
            <h1 className="title">カラコン 4択クイズ</h1>
            <p className="subtitle">スタートを押すとすぐに出題が始まります</p>
            <button className="btn primary" onClick={startGame} aria-label="クイズを開始">
              ▶︎ プレイ
            </button>
          </div>
        </section>
      )}

      {stage === 'quiz' && current && (
        <section className="page quiz" role="main" aria-live="polite">
          <header className="quiz-header">
            <div>Q {idx + 1} / {questions.length}</div>
            <div className={`timer ${remaining <= 5 ? 'warn' : ''}`}>
              残り {remaining}s
              <div className="bar">
                <div className="bar-fill" style={{ width: `${(remaining / TIME_LIMIT_SEC) * 100}%` }} />
              </div>
            </div>
          </header>

          <div className="images">
            <img src={current.imageUrls?.[0]} alt="左レンズ" />
            <img src={current.imageUrls?.[1]} alt="右レンズ" />
          </div>

          <h2 className="question">{current.title ?? 'このカラコンの名前は？'}</h2>

          <div className="choices">
            {(current.options || []).map((opt, i) => (
              <button key={i} className="btn choice" onClick={() => handleAnswer(i)}>
                {opt}
              </button>
            ))}
          </div>

          <div className="hints">
            <button className={`link ${hint1Used ? 'used' : ''}`} onClick={() => setHint1Used(true)}>
              ヒント1（SPEC）
            </button>
            <button className={`link ${hint2Used ? 'used' : ''}`} onClick={() => { setHint1Used(true); setHint2Used(true); }}>
              ヒント2（接客の一言）
            </button>
            {hint1Used && current.hints?.[0]?.text && (
              <div className="hint-box">{current.hints[0].text}</div>
            )}
            {hint2Used && current.hints?.[1]?.text && (
              <div className="hint-box">{current.hints[1].text}</div>
            )}
          </div>
        </section>
      )}

      {stage === 'result' && (
        <section className="page result">
          <div className="card result-card">
            <h2>リザルト</h2>
            <p className="score">
              合計 <strong>{result.total}</strong> 点
            </p>
            <ul className="breakdown">
              <li>正答率：{result.accuracy} / 100</li>
              <li>ヒント：{result.hintBonus} / 50</li>
              <li>タイム：{result.timeBonus} / 50</li>
            </ul>
            <button className="btn" onClick={resetAll}>ホームに戻る</button>
            {AUTO_RETURN_MS > 0 && <small>※{AUTO_RETURN_MS / 1000}秒後に自動でホームへ戻ります</small>}
          </div>
        </section>
      )}
    </div>
  );
}

```

## 4) 背景グラデーションのサイズ（ご提供画像を使う場合）

- **推奨は CSS グラデーション**（この雛形が採用）。画像不要でレスポンシブ耐性が高いです。
- もし **ビットマップ画像**を使うなら、**縦長基準 1440×2560 px（2x密度）**以上を推奨。
    - 最低：**1080×1920 px**（1x密度）
    - より安全：**2160×3840 px**（3x密度、重いので圧縮推奨）
    - 横長用を別途用意しない場合は、**中央クロップ前提**で重要要素は中心〜上部に配置。

---

## 5) 仕様・ロジックの根拠（抜粋）

- **ペイロード形とフロント構成（`questionId/imageUrls/options/hints/answerKey`）**：`phase1-core-quiz` のコンポーネント設計・クイズAPI仕様に整合。
- **スコア式（200点：正答率100 + ヒント50 + タイム50）と20秒制限**：要件定義のスコアリング記述に準拠。
- **ヒントの意味（SPEC/PR）と制限時間**：現行ルール（ヒント1=SPEC, ヒント2=一言、各20秒/問）を踏襲。
- **最小構成（ログイン無し／ホーム→クイズ→リザルト→ホーム）**：クイズ単体納品プラン / 簡易版実装計画の方針に一致。
- **画像のGitHub運用と将来のCDN化・自動検証**：exit criteria チェック & manifest 自動更新→jsDelivr リベースでの安定運用に沿う。

## 6) 追加メモ（拡張のしやすさ）

- **Supabase 併用**：今回の「ユーザーデータ非保持」では未使用ですが、後で **Supabase Storage** に画像を移す場合は `questions.json` の `imageBase` を差し替えるだけで済みます。
- **Node/サーバー側**：必要になったら結果保存APIを Node.js / Supabase Auth と接続して追加（この雛形はフロントのみで独立動作）。
- **UI素材（ロゴ/開始ボタン/背景）**：そのまま `public/` に置けば即参照できます。
