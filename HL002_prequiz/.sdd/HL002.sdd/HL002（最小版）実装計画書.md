## 2) 最適アーキテクチャ（最小・低リスク）

### A. 実装構成（保存なし版）

* **React + Vite（SPA）**：ページは **Home / Quiz / Result** の3面。状態はメモリのみ。
* **データ供給**：`/questions/questions.json`（静的）から**10問を取得**。将来は API に差し替え可能な形に。
* **画像**：`ImageProvider` で抽象化し、**GitHub(jsDelivr)** と **Supabase Storage**を**差し替え1行**で切替。
* **結果保存・ランキング**：**今回スコープ外**（UIでスコア表示のみ）。

> この方式なら、相手側が開発環境に不慣れでも**こちら側で完結**してセットアップできます。必要になれば**Supabase**への移行は `ImageProvider` を差し替えるだけ。HL001の自動化（画像リンク検証／manifest自動更新）も**ほぼそのまま再利用**できます。

### B. 画像ホスティングの選択肢

* **Option 1: GitHub → jsDelivr（推奨/既存踏襲）**

  * 既に **リンク整合性の自動チェック**と**manifest自動更新**の運用知見があるため、**初期導入が最短**。
* **Option 2: Supabase Storage（運用が楽）**

  * 画像をドラッグ&ドロップでアップ、**公開URL**がその場で得られる。**相手側の運用は直感的**。将来DBを要望されたら**同じ基盤内に拡張**できる。
* **折衷案**：まず **Option1** で最小リリース → 同一命名・同一キーの**画像manifestを維持**しつつ `ImageProvider` の実装だけ差し替えて **Option2** へ移行可能。

## 4) クイズ／スコアロジック（現状維持）

* **正答率**：`correctCount / 10 * 100`。
* **ヒントボーナス（各問）**：ヒント0=+10, ヒント1=+5, ヒント2=+0 → **最大100**。
* **タイムボーナス**：`max(0, 200 - Σ timeSpentSec)` → **最大200**。
* **総合得点**：`accuracy + hintBonus + timeBonus` → **最大400点**。
  上記は **CONTEXT.md の前提**に一致。**計算はフロントで完結**（保存なし）。

> 参考：HL001の「問題ペイロード構造（imageUrls / options / hints / answerKey）」も流用しやすいので、HL002の`questions.json`も**同じ形**に合わせると互換性が高いです。

## 9) 参考コード（雛形：型・スコア・画面）

> **型は HL001 のペイロード互換**。保存しないので最小限です。

```ts
// types.ts
export type Hint = { type: 'SPEC' | 'PITCH'; text: string };
export type Question = {
  id: string;
  imageUrls: string[];     // [left, right] も可
  options: string[];       // 4択
  answerIndex: number;     // 0..3
  hints: Hint[];           // [SPEC, PITCH]
};

export type Answer = { choiceIndex: number; timeSpentSec: number; hintsUsed: 0|1|2 };

export type ScoreBreakdown = {
  accuracy: number;    // 0..100
  hintBonus: number;   // 0..100
  timeBonus: number;   // 0..200
  total: number;       // 0..400
};

// score.ts (CONTEXTの式を踏襲)
export function calcScore(questions: Question[], answers: Answer[]): ScoreBreakdown {
  const total = questions.length;
  const correctFlags = answers.map((a,i)=> a.choiceIndex === questions[i].answerIndex);
  const correctCount = correctFlags.filter(Boolean).length;
  const accuracy = Math.round((correctCount / total) * 100);

  // 正解時のみボーナス加点
  const hintBonus = correctFlags.reduce((sum, ok, i) => {
    if (!ok) return sum;
    const used = answers[i].hintsUsed;
    return sum + (used === 0 ? 10 : used === 1 ? 5 : 0);
  }, 0);

  const timeSpentSum = answers.reduce((s,a)=> s + a.timeSpentSec, 0);
  const rawTimeBonus = Math.max(0, 200 - timeSpentSum); // 10問×20秒 = 200
  // 不正解分の時間はCONTEXTの前提にあわせ、単純合算から差し引かず最大200を上限管理
  const timeBonus = Math.min(200, rawTimeBonus);

  return { accuracy, hintBonus, timeBonus, total: accuracy + hintBonus + timeBonus };
}
```

```tsx
// App.tsx（骨子）
function App() {
  const [page, setPage] = useState<'home'|'quiz'|'result'>('home');
  const [qs, setQs] = useState<Question[]>([]);
  const [ans, setAns] = useState<Answer[]>([]);
  const [current, setCurrent] = useState(0);

  const start = async () => {
    setAns([]); setCurrent(0);
    const data = await fetch('/questions/questions.json').then(r=>r.json());
    setQs(data); setPage('quiz');
  };

  const answer = (choiceIndex:number, timeSpentSec:number, hintsUsed:0|1|2) => {
    const next = [...ans, { choiceIndex, timeSpentSec, hintsUsed }];
    setAns(next);
    if (next.length >= qs.length) setPage('result'); else setCurrent(c=>c+1);
  };

  return (
    <>
      {page==='home'   && <Home  onStart={start} />}
      {page==='quiz'   && <Quiz  q={qs[current]} idx={current} total={qs.length} onAnswer={answer} />}
      {page==='result' && <Result score={calcScore(qs, ans)} onBack={()=>setPage('home')} />}
    </>
  );
}
```
