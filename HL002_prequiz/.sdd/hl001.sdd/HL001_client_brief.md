# HL001 クライアントブリーフ（詳細版）

## 1. プロジェクト概要
- プロダクト：カラーコンタクトの名称当てクイズアプリ
- 対象フェーズ：フェーズ1（練習モード／採点／ランキングダッシュボード）
- 目的：クライアントが求める到達点と実作業量のギャップを可視化し、適切な費用を提示できる資料を用意する

## 2. 要件整理
| 大項目 | 内容 | 現状 | 備考 |
| --- | --- | --- | --- |
| クイズコア | 画像＋名称4択、10問構成 | 実装済み | 画像のCDN最適化完了 |
| リザルト | 正答率表示、再挑戦導線 | 実装済み | UI仕上げ待ち |
| ランキング | 日次／累積ランキング | ロジック設計済み | API・UIは未着手 |
| ダッシュボード | 練習履歴／学習状況可視化 | 要件凍結中 | 後続フェーズに回す案 |
| CMS連携 | 画像・データ更新フロー | 自動検証ツール実装 | manifest自動更新あり |

## 3. 進捗サマリ
- 画像・データ検証
  - `tools/check_exit_criteria.js` により CSV/manifest/CDN の整合性チェックを自動化
  - `tools/auto_update_manifest.js` で HTTP200 の画像のみ manifest に反映
- UI/UX
  - ホーム＋ゲーム画面の構造は決定済み（サイバーパンク調）
  - デザイン反映に時間を要し、ダッシュボード系は未実装
- インフラ／自動化
  - GitHub Actions で毎日／PR毎に整合性チェックを実行
  - manifest 自動更新ワークフローを実装（PR作成まで自動）

## 4. ボトルネックと対応策
1. **UI調整の属人化**
   - Figma等へのデザイン移植が遅延 → HTML/CSSベースの仮UIで一旦クローズし、必要なら後日デザイナーに委託
2. **画像・データ不整合**
   - 画像欠損／リンク切れが多発 → 自動検証ラインを運用し、CDN置換スクリプトで読み込み高速化
3. **当初要件の過大化**
   - ダッシュボード・ランキングまで含めると数百時間規模 → クライアント合意の上、フェーズ1を「クイズ体験の完成」にスコープ縮小

## 5. 費用・期間試算
- **前提条件**：開発者1名あたり 1日8時間、実効稼働 5日／週、追加ディレクション10%を計上
- 体制別目安
  - フリーランス1名：6〜8週間、150〜180h → 90〜120万円
  - 小規模チーム（2〜3名）：4〜6週間、160〜200h → 150〜220万円
  - 中規模チーム（5〜7名）：3〜5週間、220〜260h → 260〜340万円
  - 大規模チーム（10名以上）：2〜4週間、280h〜 → 380万円以上
- **推奨提示額**：最小構成で100万円程度を目安に提示。ランキング／ダッシュボード追加時は都度見積り。

## 6. 今後のステップ
1. クライアントへ本ブリーフを共有し、フェーズ1の再定義を合意
2. UI仕上げと動作確認を Codex に割り当て、2営業日以内にデモURLを提出
3. manifest／データ更新手順を docs/README.md・docs/DATA_UPDATE.md にまとめ、運用引き継ぎ
4. フェーズ2要件（ランキング等）について優先度と予算枠を再交渉
