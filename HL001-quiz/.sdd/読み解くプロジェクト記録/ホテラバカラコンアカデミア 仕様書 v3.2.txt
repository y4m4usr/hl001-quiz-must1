1. アプリ概要
項目	内容
名称	ホテラバカラコンアカデミア（Hotel Baccarat × 学習クイズアプリ）
利用者	ホテラバカラコン従業員＋アカデミア受講者
提供機能	カラコン識別クイズ、本番／練習モード、ランキング、マイ成績、管理者分析
フロントエンド	Google Apps Script HTML Service（index.html 等）
バックエンド	Google Apps Script（*.gs, *.js）、GAS API経由で各シートを参照／更新
データ格納	Google Sheets（USERS, HISTORY, TITLES, RANKINGS など）
2. クイズ仕様（v3.1から継承）
出題数: 1セッション10問／各問4択／制限時間20秒

ヒント: 1問につき最大2種

ヒント1: カラコン SPEC（DIA / G.DIA / BC）
ヒント2: PR コメント
スコア計算（最大200点／v3.1より変更なし）

項目	内容
正答率	正解数 × 10（最大100）
ヒントボーナス	正解かつヒント未使用で+5、1件使用で+2（合計最大50）
タイムボーナス	正解かつ残り秒の合計÷4（合計最大50）
合計	score = accuracy + hintBonus + timeBonus（0〜200）
ヒント利用時の減算はないがヒントボーナスが減るため実質ペナルティになる

タイムアウト時や未回答は selectAnswer(null, question) を呼び出し不正解扱い

3. HISTORY・メタデータ（v3.1から継承）
HISTORY シート： v11 形式（1回答＝1行）
主列: historyId, timestamp, userId, mode, questionId, isCorrect, hintsUsed, timeSpent, score
metadata(JSON) 例：
{
  "accuracy": 80,
  "hintBonus": 30,
  "timeBonus": 25,
  "correctCount": 8,
  "expEarned": 95,
  "rpEarned": 80,
  "streakAfter": 5,
  "boost": 1.3,
  "levelAfter": 12,
  "pointsAfter": 1850
}
1セッション（10問）中の最後の行にトータルスコア関連が入る
4. モード／streak 管理（v3.1継承）
項目	内容
mode 値	daily（本番）／ practice（練習）
本番制限	1日1回（USERS.I:lastDailyDateで制御）
streak 更新	連続日数（2日連続で+1、2日以上空くと1）
練習	回数制限なし／streakは更新しない
5. EXP / RP / レベル（v3.1継承）
項目	内容
本番EXP	totalScore × ブースト
本番RP	totalScore
練習EXP	round(accuracy / 10)（最大10）
練習RP	0
ブースト値	streak=2:1.1,3:1.2,4:1.3,5:1.4,6:1.5,7以上:1.5
レベル曲線	req[Lv] = req[Lv-1] + round((Lv-1)^1.5 × 100) 上限Lv=30
称号	TITLES シート [level, title] の上限値を採用（例：Lv1=ルーキー）
6. ランキング（v3.1継承）
getRanking(scope) で直近履歴を集計し統計返却
scope: daily / weekly / monthly / yearly
daily はランキング表の出力対象外（screenでのタブ初期値は weekly）
updateRankingsAllScopes() で rankings シートに weekly/monthly/yearly を縦連結保存
ランキング表示はバッジ／メダルで強調
課題（v3.2時点）: tie-breaker 明文化、dailyタブ整理
7. マイ成績（v3.1継承）
getMyStats(userId) で直近 10 セッションを返却
表示要素
日付／モード表示
正答率／ヒント／タイム／EXP／RP 内訳
合計スコア（点）＋正答率
上部には EXP/RP 合計／棒グラフ（EXP,RP の推移）
UI改善案: Chart.js への置換、フィルタ機能を検討
